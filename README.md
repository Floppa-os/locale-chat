# locale-chat
Конфигурация мессенджера находится в файле **`config.py`** в корне проекта.


### Что там хранится

В этом файле задаются ключевые параметры работы системы:

1. **Настройки сервера**  
   * `SERVER_HOST` — IP‑адрес, на котором запускается сервер (например, `'0.0.0.0'` для приёма подключений со всех интерфейсов).  
   * `SERVER_PORT` — порт сервера (по умолчанию `8888`).

2. **Настройки клиента**  
   * `CLIENT_HOST` — локальный IP‑адрес клиента (например, `'127.0.0.1'`).  
   * `CLIENT_PORT` — локальный порт клиента (по умолчанию `8889`).

3. **Пути и лимиты**  
   * `DOWNLOAD_DIR` — папка для сохранения принятых файлов (например, `'./downloads'`).  
   * `MAX_FILE_SIZE` — максимальный размер передаваемого файла в байтах (по умолчанию `10 * 1024 * 1024`, т. е. 10 МБ).

### Как использовать

1. Откройте файл `config.py` в корне проекта.  
2. Измените значения переменных под свои нужды (например, поменяйте порты или путь к папке загрузки).


### Почему именно так

* **Централизация.** Все настройки в одном месте — легко менять и документировать.  
* **Разделение окружения.** Отдельные параметры для сервера и клиента позволяют запускать их на разных машинах или портах.  
* **Гибкость.** Пути и лимиты можно адаптировать под конкретную инфраструктуру.

> **Примечание:** Если вы публикуете проект на GitHub, убедитесь, что в `config.py` нет ваших личных данных и других штук (паролей, логинов, ключей, шлёпиков)
